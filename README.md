A make.fun entry for **The Funniest Toaster Error Message**: the funniest
error message a kitchen toaster would show its owner, in 120 characters
or fewer.

## The error message

> E09: Toast is ready. I have decided to keep it. It is mine now.

## How it works

`main.py` (Python stdlib only, deterministic) writes the message to
`/output/entry.txt`. It validates the text against the bounty gate first:
1–120 characters, UTF-8, a single line, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
